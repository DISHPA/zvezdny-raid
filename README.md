# ЗВЁЗДНЫЙ РЕЙД ★

Пиксельный идл-кликер для Telegram: герой бежит по галактике, бьёт монстров, а ты
прокачиваешь урон, скорость и отряд дронов. Один файл `index.html`, без сборки,
без внешних ассетов и без интернета — вся графика рисуется на `<canvas>`.

## Как играть

| Действие | Что делает |
|---|---|
| **Тап / клик по экрану** | Ручной удар — множитель к DPS, помогает на боссах |
| **Кнопка «МАГАЗИН»** | Улучшения и престиж |
| **Автоатака** | Герой бьёт сам, без тапов |

Герой бежит вправо по бесконечным зонам. В каждой зоне 10 стадий, на 10-й — босс
(×7 HP, ×14 золота). Убил босса — перешёл в следующую зону. Если монстр убил
героя — откат на одну зону назад и стадия сбрасывается.

### Вкладки магазина

- **АТАКА** — урон, скорость удара, крит, крит-урон, сила тапа, добыча золота
- **ЗАЩИТА** — здоровье, регенерация, броня
- **ОТРЯД** — дрон, спутник, луноход: пассивный DPS, работает в оффлайне
  (дрон с зоны 1, спутник — с 6, луноход — с 14)
- **ПРЕСТИЖ** — сброс прогресса за души: каждая душа даёт **+15 %** к урону и золоту

### Экономика

- Цена улучшения растёт экспоненциально: `base × growth^уровень`
- HP монстра: `8 × 1.70^(зона−1)` (`×7` на боссе)
- Золото с монстра: `4 × 1.50^(зона−1)` (`×14` на боссе)
- Престиж доступен с 5-й зоны, души: `floor((всего золота / 1200)^0.45)`

Ориентир темпа (симуляция с автопокупкой): зона 3 за 5 минут, зона 10 за 15 минут,
зона 22 за 30 минут, зона 36 за час.

### Оффлайн-доход

Игра сохраняется каждые 5 секунд и при закрытии. Вернулся через час — получишь
**45 %** от своего DPS за прошедшее время, но не более чем за **8 часов**.

Прогресс лежит в `localStorage` под ключом `zvezdraid.save.v1`.

## Публикация на GitHub Pages

1. Создай репозиторий (например, `zvezdny-raid`), публичный.
2. Загрузи `index.html` в корень ветки `main`.
3. **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.**
4. Через минуту игра откроется по адресу
   `https://<твой-логин>.github.io/zvezdny-raid/`.

Проверить, что страница отдаётся: открыть этот URL в браузере — должен появиться
заголовок «ЗВЁЗДНЫЙ РЕЙД» и кнопка «ИГРАТЬ».

> Файл должен называться именно `index.html` — тогда GitHub Pages отдаст его как
> главную страницу каталога.

## Подключение к Telegram как Mini App

**Уже сделано** (бот живёт, приложение открывается):

- Адрес: <https://dishpa.github.io/zvezdny-raid/>
- Бот: <https://t.me/zvezdny_raid_bot> — имя «Звёздный Рейд»
- Кнопка меню в чате: **PLAY** → открывает Mini App
  (`getChatMenuButton` отдаёт `{"type":"web_app","text":"PLAY", ...}`)
- Заданы описание бота, короткое описание и команда `/start`

Как это сделано с нуля:

1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получи токен и юзернейм бота.
2. `/newapp` → выбери бота → задай название, описание, иконку 640×360.
3. **Web App URL** — адрес с GitHub Pages из шага выше (обязательно HTTPS).
4. Проверь: `/myapps` → у приложения есть кнопка «Open».
5. Кнопка в чате: `/setmenubutton` → выбери бота → вставь тот же URL → задай
   подпись, например «Играть».

Без BotFather то же самое делается через Bot API (нужен только токен):

```bash
# кнопка меню
curl -X POST "https://api.telegram.org/bot<TOKEN>/setChatMenuButton" \
  -H "Content-Type: application/json" \
  -d '{"menu_button":{"type":"web_app","text":"PLAY","web_app":{"url":"https://dishpa.github.io/zvezdny-raid/"}}}'
# описания
curl -X POST "https://api.telegram.org/bot<TOKEN>/setMyDescription" \
  -H "Content-Type: application/json" -d '{"description":"..."}'
```

> Из России `api.telegram.org` открывается только через VPN/прокси — например,
> `curl --proxy http://127.0.0.1:10809 ...`.

Дальше игра открывается прямо в Telegram: `window.Telegram.WebApp` сам вызовет
`ready()` и `expand()`, подгонит цвет шапки и включит вибро-отклик на ударах.
Вне Telegram ничего не ломается — игра работает как обычная веб-страница.

## Управление и совместимость

- Мышь и тач, игра подстраивается под любой размер экрана (портрет и ландшафт).
- Звук — синтезированные сигналы WebAudio, отключается кнопкой в меню.
- Никаких сетевых запросов: одна страница, ноль зависимостей.
